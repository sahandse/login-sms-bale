# ورود با پیامک و بله

افزونه ورود و ثبت‌نام وردپرس با شماره موبایل، کد یکبارمصرف و اتصال به بله.

## ویژگی‌ها
- ورود/ثبت‌نام با شماره موبایل
- OTP
- آماده اتصال ملی‌پیامک، فراز SMS و سایر سرویس‌ها
- ورود با بله
- رابط فارسی و مینیمال
- چند تم برای فرم ورود
- ساختار مناسب WooCommerce و صفحات حساب کاربری
