== Description ==
Login SMS Bale provides the settings and frontend foundation for OTP-based mobile login and Bale authentication.

== Installation ==
1. Upload the login-sms-bale folder to /wp-content/plugins/
2. Activate the plugin.
3. Open ورود پیامکی from WordPress admin.
4. Add [login_sms_bale] to a page.
